# DARKTECH Watch Face for Garmin

DARKTECH is a modern, tactical, and data-driven watch face designed for Garmin devices, combining a clean digital interface with essential daily metrics.

## Features (Free Version)
* Crisp and clear digital time display
* Date and day indicator
* Battery status indicator with percentage ring
* Step counter
* Designed for both round and rectangular Garmin displays

## Project Structure
* `source/` - Monkey C source code
* `resources/` - App resources, graphics, and string definitions
* `manifest.xml` - App configuration and permissions
* `monkey.jungle` - Build configuration file
